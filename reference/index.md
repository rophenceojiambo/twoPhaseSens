# Package index

## Run a sensitivity analysis

Generate example two-phase data and compare the supported analytic
methods.

- [`twophase_example_data()`](https://rophenceojiambo.github.io/twoPhaseSens/reference/twophase_example_data.md)
  : Generate a synthetic two-phase example dataset
- [`twophase_sensitivity()`](https://rophenceojiambo.github.io/twoPhaseSens/reference/twophase_sensitivity.md)
  : Compare methods for Phase-2 covariates missing by design

## Summarize and diagnose

Create the sensitivity-analysis table and inspect method-level
diagnostics.

- [`tbl_sensitivity()`](https://rophenceojiambo.github.io/twoPhaseSens/reference/tbl_sensitivity.md)
  : Create a publication-ready sensitivity-analysis table
- [`diagnostics()`](https://rophenceojiambo.github.io/twoPhaseSens/reference/diagnostics.md)
  : Extract diagnostics from a twoPhaseSens analysis

## Visualize results

Create publication-style forest plots of the method comparison.

- [`plot_sensitivity()`](https://rophenceojiambo.github.io/twoPhaseSens/reference/plot_sensitivity.md)
  [`plot(`*`<twophase_sensitivity>`*`)`](https://rophenceojiambo.github.io/twoPhaseSens/reference/plot_sensitivity.md)
  : Plot sensitivity-analysis estimates and confidence intervals
